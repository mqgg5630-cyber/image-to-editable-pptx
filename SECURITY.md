# Security policy

## Supported version

Security fixes target the latest tagged release.

## Reporting

Do not post sensitive documents, credentials, access tokens, or private slide content in a public issue. Report security concerns privately through GitHub's repository security reporting feature when enabled, or contact the repository owner through their GitHub profile.

## Data handling

The included scripts operate on local files and do not require outbound network requests. Users remain responsible for the confidentiality and redistribution rights of source images, presentation files, fonts, and image assets.
